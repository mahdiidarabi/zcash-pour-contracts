# contracts

  Hardhat project for the pour pool and the generated Groth16 verifier.
  Spec: [`../docs/protocol.md`](../docs/protocol.md).

  ## Structure

  ```
  contracts/
  ├── ZcashPourPool.sol          # the pool: mint / pour / burn
  └── verifiers/
      └── ZcashPourVerifier.sol  # GENERATED by ../circuits — do not edit
  test/
  ├── ZcashPour.test.ts          # pool + mint
  ├── ZcashPourPour.test.ts      # pour
  ├── ZcashPourBurn.test.ts      # burn
  └── helpers/gasReporter.ts
  scripts/                       # deploy
  deployments/                   # deployed addresses per network
  ```

  `mint` shields ETH into a commitment, `pour` spends notes and creates new ones behind
  a proof, `burn` unshields back to an address.

  ## Setup
  
  ```bash
  npm install
  cp env.example .env     # fill in for Sepolia; not needed for local
  ```

  The verifier is committed, so this compiles without running the ceremony. To regenerate
  it after changing the circuit:

  ```bash
  cd ../circuits && npm run all ZcashPour 16
  ```

  ## Run

  ```bash
  npx hardhat compile
  npx hardhat test
  npx hardhat test test/ZcashPourPour.test.ts   # one file
  REPORT_GAS=true npx hardhat test
  ```

  Deploy:

  ```bash
  npx hardhat run scripts/deploy.ts --network sepolia
  ```
